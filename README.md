# Letrilandia

Lupi y el Libro Mágico: un juego para aprender a leer, para chicos de 3 a 5 años.

Jugar: https://fercala.github.io/letrilandia/

Se puede instalar en el celular o la tablet desde el navegador (Android: menú ⋮ › «Instalar aplicación»; iPhone: Compartir › «Agregar a inicio»). Después de abrirlo una vez, funciona sin internet.
